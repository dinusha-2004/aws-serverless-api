# ⚡ Serverless REST API — AWS Lambda + DynamoDB

A fully serverless REST API built with AWS Lambda, API Gateway, and DynamoDB for Todo management.

## 🚀 Live API
- **API URL:** https://xo755o5p46.execute-api.eu-north-1.amazonaws.com/prod/todos

## 🛠️ Tech Stack
- AWS Lambda — Python 3.12
- AWS API Gateway — REST API
- AWS DynamoDB — NoSQL Database
- AWS IAM — Role-based permissions

## ☁️ AWS Architecture
User → API Gateway → Lambda (Python) → DynamoDB

## 📌 API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /todos | Get all todos |
| POST | /todos | Add a new todo |
| DELETE | /todos | Delete a todo |
